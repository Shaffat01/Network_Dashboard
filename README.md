# 🌐 Network Infrastructure Dashboard

A comprehensive network infrastructure monitoring dashboard that collects 
and displays switch information via SNMP and SSH.

## Features
- 📋 CSV import for device (switch) inventory
- 🔍 SNMP & SSH based data collection
- 📊 Beautiful web dashboard with left navigation
- 🏷️ VLAN listing per switch
- 🌐 VLAN IP address mapping
- 🔐 RADIUS server detection
- 📝 Log server configuration
- ⚙️ SNMP server configuration
- 📋 Syslog entries viewer
- 🔗 CDP neighbor discovery
- 🐳 Fully Dockerized
- 🔄 CI/CD with Jenkins
